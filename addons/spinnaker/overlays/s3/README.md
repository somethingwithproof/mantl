S3 overlay (Front50 storage)

This overlay configures Spinnaker Front50 to use Amazon S3 and reads credentials from a Kubernetes Secret generated by kustomize.

Steps
1) Create a file named s3.env in this directory with:
   accessKeyId=AKIA...
   secretAccessKey=...

2) Edit patch-s3.yaml to set:
   - bucket: your S3 bucket
   - region: your AWS region

3) Apply the overlay:
   kubectl apply -k addons/spinnaker/overlays/s3

Notes
- s3.env should not be committed to version control.
- The SpinnakerService references these values via secretManagement (encrypted:k8s...).
